# 기억의 정원 🌷

한국어로 즐기는 기억력 짝맞추기 웹 게임입니다.

## 실행

저장소를 다운로드한 뒤 `index.html`을 브라우저에서 열면 됩니다. 설치나 서버가 필요 없습니다.

## 기능

- 난이도 3단계: 6쌍, 8쌍, 12쌍
- 플레이 시간, 시도 횟수, 찾은 짝 표시
- 난이도별 최고 기록을 브라우저에 저장 (시도 횟수 우선, 동률이면 시간 순)
- 새로 시작, 완료 후 재도전
- 모바일 대응, 키보드 Tab/Enter 조작, 움직임 줄이기 설정 대응

## GitHub Pages로 공개하기

저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택하고, **main / (root)**를 저장하세요. 배포가 끝나면 `https://2010scig-ship-it.github.io/Seocho/`에서 플레이할 수 있습니다.

기록은 해당 브라우저에만 저장되며, 의료용 인지 검사나 진단 도구가 아닙니다.
